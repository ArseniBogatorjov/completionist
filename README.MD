# Completionist
**Completionist** is an app created for gamers who want to track their Steam achievements and complete their games at 100%.
Track your progress, see which achievements you've unlocked, and find out what you still need to do to become a true completionist.

# Data sources
Completionist uses the Steam Web API as its primary source for game and achievement data.

For additional achievement information that is not provided by Steam, such as missable status and game chapters. Completionist uses data from the [Achievement Scavenger Database](https://github.com/batureren/achievement-scavenger-database).

The Scavenger Database is a community-maintained open-source project containing additional achievement information and guides.
